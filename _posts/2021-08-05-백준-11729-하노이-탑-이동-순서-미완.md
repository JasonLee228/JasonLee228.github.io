[11729번: 하노이 탑 이동 순서](https://www.acmicpc.net/problem/11729)

### 문제

> 💡 세 개의 장대가 있고 첫 번째 장대에는 반경이 서로 다른 n개의 원판이 쌓여 있다. 각 원판은 반경이 큰 순서대로 쌓여있다. 이제 수도승들이 다음 규칙에 따라 첫 번째 장대에서 세 번째 장대로 옮기려 한다.
>
> 1. 한 번에 한 개의 원판만을 다른 탑으로 옮길 수 있다.
> 2. 쌓아 놓은 원판은 항상 위의 것이 아래의 것보다 작아야 한다.
>
> 이 작업을 수행하는데 필요한 이동 순서를 출력하는 프로그램을 작성하라. 단, 이동 횟수는 최소가 되어야 한다.
>
> 아래 그림은 원판이 5개인 경우의 예시이다.

![image](/assets/images/12dc86ba9f7c4543802b3c20bb1eb932.png)

### 입력

> 💡 첫째 줄에 첫 번째 장대에 쌓인 원판의 개수 N (1 ≤ N ≤ 20)이 주어진다.

---

### 출력

> 💡 첫째 줄에 옮긴 횟수 K를 출력한다.
>
> 두 번째 줄부터 수행 과정을 출력한다. 두 번째 줄부터 K개의 줄에 걸쳐 두 정수 A B를 빈칸을 사이에 두고 출력하는데, 이는 A번째 탑의 가장 위에 있는 원판을 B번째 탑의 가장 위로 옮긴다는 뜻이다.

### 원리

> 💡 하노이탑의 풀이 횟수는 2^n-1이라고 알려져 있다.(출처 : [위키백과](https://ko.wikipedia.org/wiki/%ED%95%98%EB%85%B8%EC%9D%B4%EC%9D%98_%ED%83%91))
> A,B,C타워가 있다고 할 때, N번째의 블록이(가장 큰) C타워로 옮겨지기 위해서는 N-1번째까지의 블록들이 B타워로 옮겨져야 하고(빈 공간 = B), 이를 반복하면 결국 가장 작은 타워까지 오게 된다. 라는 식의 원리인데 아직 잘 모르겠다 ㅎㅎ,,

> 💡 다시 설명하자면, 3개의 원판으로 하노이의 탑을 풀이한다고 했을 때, 
> 3번째(가장 큰)블록을 옮기기 위해서는 2번째 까지의 블록을 B타워로 옮겨야 한다. //1.
> 이후 3번째 블록을 C타워로 옮겨준다.//2.
> 3번째 블록이 C타워로 옮겨졌다면, B타워로 초점을 바꾸면 된다. 
>
> B타워에 있는, 두 번째 블록을 C타워로 옮기기 위해서는 나머지 블록, 곧 첫 번째 블록이 빈 타워인 A타워로 옮겨져야 두 번째 블록을 C타워로 옮길 수 있다. //3.
>
> 두 번째 블록이 옮겨졌다면, 이제 마지막 남은 하나의 블록을 옮겨주면 되는 것이다.
> 위 과정을 재귀적으로 반복하다 보면, 코드상으로 n==1이 되는 상황이 되고, 해당 상황이 된다면 옮겨주는 것이다.

### 풀이 코드(최종)

{% raw %}
```java
import java.util.*;

class Main {
    public static StringBuilder sb = new StringBuilder();
    public static void hanoi(int num, int start, int mid, int end)
    {
        if(num == 1)
        {
            sb.append(start + " " + end + "\n");
            return;
        }
        hanoi(num-1,start,end,mid);  //1.
        hanoi(1,start,mid,end);//2.
        hanoi(num-1,mid,start,end);//3.
    }

	static public void main(String []args) {
		Scanner s = new Scanner(System.in);
        int n = s.nextInt();
        sb.append((int)Math.pow(2, n)-1 + "\n");4.
        hanoi(n,1,2,3);
       System.out.println(sb); 
    }
}
```
{% endraw %}

### 코드 설명 

> 💡 hanoi(현재 블록 수, 시작 타워, 서브 타워, 옮길 타워)
> 의 형태이며, 주석처리 해 둔 부분들의 설명은 다음과 같다.
>
> 1. 맨 밑의 가장 큰 블록이 옮겨지기 위해서 나머지 블록을 B타워로 옮겨줌
> 2. 나머지 블록이 옮겨졌으므로 N번째 블록을 C타워로 옮겨줌
> 3. 이후 빈 공간인 A타워를 이용해 다른 블록들을 순차적으로 옮겨줌
> 이라는 원리다.
>
> 4. 출력의 첫 번째 문장에는 실행횟수인 2^n-1을 출력해 준다.
>
> 출력은 print문을 반복하게 되면 시간초과가 나므로, StringBuilder를 이용해 출력해 준다.

> 💡 개인적인 이해를 돕기 위해 n == 1인 경우, 블록을 다른 타워로 옮기는 경우를 출력해 주도록 덧붙이니, 다음과 같이 출력됐다.
