1. 소수?

> 💡 소수(prime number)는 1보다 큰 자연수 중 1과 자기 자신만을 약수로 가지는 수다. 
> 예를 들어, 5는 1×5 또는 5×1로 수를 곱한 결과를 적는 유일한 방법이 그 수 자신을 포함하기 때문에 5는 소수이다. 그러나 6은 자신보다 작은 두 숫자(2×3)의 곱이므로 소수가 아닌데, 이렇듯 1보다 큰 자연수 중 소수가 아닌 것은 합성수라고 한다. 1과 그 수 자신 이외의 자연수로는 나눌 수 없는 자연수로 정의하기도 한다. 
> ([출처 - 위키백과](https://ko.wikipedia.org/wiki/%EC%86%8C%EC%88%98_(%EC%88%98%EB%A1%A0)))

> 💡 이러한 소수가 중요한 이유는 바로 '보안성' 에 있다. 소수는 소인수분해와 직결되는데, 소인수분해의 정의에 따라서 1보다 큰 모든 자연수는 모든 소수의 곱으로 표현할 수 있다. 
>
> 그렇다면 자연수의 표현이 보안성과 무슨 연관이 있을까? 
> 소수를 이용한 암호화 표현에는 이런 개념이 있다.
> **"임의의 수들의 곱은 구하기 쉽지만 역으로 소인수 분해하는 것은 어렵다."**
> 즉, 𝑝 × 𝑞 = 𝐍 를 만들기는 쉽지만,  𝐍 을 역으로 소인수 분해하여 𝑝 × 𝑞 를 만족하는 수를 찾기가 어렵다는 것이다.
> 17,29 등과 같이 간단한 소수의 판별은 쉽게 표현이 가능하지만, 12126과 같이 5자리가 넘어가는 소수라면 직관적인 소인수분해가 힘들 것이라는 원리이다.
> 위 방식을 이용한 암호화 방식이 'RSA-암호화 방식'이다.

1. 소수를 구하는 방법으로는 대표적으로 3가지가 있다. 숫자 N이 주어졌을 때, N이 소수인지 판별하는 방법은,

> 💡 - N이하의 자연수로 모두 나눠보기.
> - $√N$이하의 자연수로 모두 나눠보기.
> - 에라토스테네스의 체

이렇게 3가지이다. 효율성은 아래로 내려갈 수록 더욱 더 좋아진다. 이제 아래에서 자세한 방법을 다뤄보자.

- N이하의 자연수로 모두 나눠보기

> 💡 소수는 자기 자신과 1 이외에는 약수를 가질 수 없다. 때문에,  1과 자기 자신 이외의 다른 수로 나눠진다면 소수가 아니라는 얘기가 된다.

- 에라토스테네스의 체

- 소스 코드

{% raw %}
```java
import java.util.*;

public class Main {

	public static void main(String[] args) {
		Scanner sc = new Scanner(System.in);
		int t1 = sc.nextInt();
		int t2 = sc.nextInt();
		int check = 0;

		for (int i = t1; i <= t2; i++) {
			if (i == 1) {
				check = 1;
			}
			int tt2 = (int) Math.sqrt(i) + 1;
			for (int j = 2; j < tt2; j++) {
				if (i % j == 0) {
					check = 1;
					break;
				}
			}

			if (check == 0) {
				System.out.println(i);
			}
			check = 0;
		}
	}
}
```
