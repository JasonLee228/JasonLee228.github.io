### 문제

> 💡 1보다 큰 자연수 중에서  1과 자기 자신을 제외한 약수가 없는 자연수를 소수라고 한다. 예를 들어, 5는 1과 5를 제외한 약수가 없기 때문에 소수이다. 하지만, 6은 6 = 2 × 3 이기 때문에 소수가 아니다.
>
> 골드바흐의 추측은 유명한 정수론의 미해결 문제로, 2보다 큰 모든 짝수는 두 소수의 합으로 나타낼 수 있다는 것이다. 이러한 수를 골드바흐 수라고 한다. 또, 짝수를 두 소수의 합으로 나타내는 표현을 그 수의 골드바흐 파티션이라고 한다. 예를 들면, 4 = 2 + 2, 6 = 3 + 3, 8 = 3 + 5, 10 = 5 + 5, 12 = 5 + 7, 14 = 3 + 11, 14 = 7 + 7이다. 10000보다 작거나 같은 모든 짝수 n에 대한 골드바흐 파티션은 존재한다.
>
> 2보다 큰 짝수 n이 주어졌을 때, n의 골드바흐 파티션을 출력하는 프로그램을 작성하시오. 만약 가능한 n의 골드바흐 파티션이 여러 가지인 경우에는 두 소수의 차이가 가장 작은 것을 출력한다.

---

### 입력

> 💡 첫째 줄에 테스트 케이스의 개수 T가 주어진다. 각 테스트 케이스는 한 줄로 이루어져 있고 짝수 n이 주어진다.

---

### 출력

> 💡 각 테스트 케이스에 대해서 주어진 n의 골드바흐 파티션을 출력한다. 출력하는 소수는 작은 것부터 먼저 출력하며, 공백으로 구분한다.

### 풀이 코드

{% raw %}
```java
package test;
import java.util.*;
public class Main {

	public static void main(String[] args) {//9020, 골드바흐의 추측
		Scanner s = new Scanner(System.in);
		int test=0;
		test = s.nextInt();
		
		boolean[] ara = new boolean[10001];//1.
		//2.
		for(int i=0;i<10001;i++)
			ara[i] = true;
		ara[0]=ara[1] = false;
		
		 for(int i=2; i*i<10001; i+=1) {
	            for(int j=i*i; j<10001; j+=i) {
	                ara[j] = false;        //2를 제외한 2의 배수 false
	            }
	        }
		
		
		 
		 for(int i=0;i<test;i++)
		 {
			 int num = s.nextInt();
			 
			 int under,next;
			 under = next = num/2;
			 
			 while(true)//3.
			 {
				 if(ara[under] == true && ara[next] == true)
				 {
					 System.out.println(under+" "+next);
					 break;
				 }
				 else {
					under--;next++;
				}
				 
			 }
		 }
	}
}
```
{% endraw %}

### 코드 설명 

> 💡 1. 문제에서 10000까지의 수에 대해서는 골드바흐 파티션이 존재한다고 했으니 10000까지로 케이스를 맞춰준다(4 ≤ n ≤ 10,000)
>
> 2. 에라토스테네스의 체를 통해 10000까지의 소수를 먼저 구현해 준다. 에라토스테네스의 체에 관련된 부분은 아래 링크를 통해 확인할 수 있다.
>

[[JAVA, 자바]에라토스테네스의 체](https://www.notion.so/JAVA-051f7269f8fe4b8ea40a67977b25da69)

> 💡 3. 언뜻 보면 '가장 가까이 붙어 있는 소수'에 관해서 어떻게 생각해야 할 지에 대한 문제가 가장 큰 관건일 것이다. 하지만 이는 조금만 생각해 보면 풀릴 수 있는 간단한 문제이다.
> 각 case에 대한 수를 '반으로' 나누는 것을 생각하면 된다. 수를 반으로 나눈 뒤, 반으로 나누어진 두 수를 각각 under, next에 저장해 준다. 
> 이후 under과 next를 하나씩 줄이고 늘려가며 소수를 판별해 준다. 결국 under,next 둘을 더하게 되면 기존 숫자가 나올 것이니.
