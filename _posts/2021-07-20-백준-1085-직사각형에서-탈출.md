### 문제

> 💡 한수는 지금 (x, y)에 있다. 직사각형의 왼쪽 아래 꼭짓점은 (0, 0)에 있고, 오른쪽 위 꼭짓점은 (w, h)에 있다. 직사각형의 경계선까지 가는 거리의 최솟값을 구하는 프로그램을 작성하시오.

---

### 입력

> 💡 
>
> 첫째 줄에 x, y, w, h가 주어진다.  
>   
> #제한사항  
> 1 ≤ w, h ≤ 1,000  
> 1 ≤ x ≤ w-1  
> 1 ≤ y ≤ h-1  
> x, y, w, h는 정수

---

### 출력

> 💡 첫째 줄에 문제의 정답을 출력한다.

---

### 예제 입력 1

{% raw %}
```text
6 2 10 3
```
{% endraw %}

### 예제 출력 1

{% raw %}
```text
1
```
{% endraw %}

---

### 풀이 코드

{% raw %}
```java
package test;
import java.util.*;
public class Main {

	public static void main(String[] args) {//1085, 직사각형 탈출
		Scanner s = new Scanner(System.in);
	
		int x = s.nextInt();
		int y = s.nextInt();
		int w = s.nextInt();
		int h = s.nextInt();
		
		s.close();
		
		
		 
		int x_min = Math.min(x, w-x);	// x축 최소거리
		int y_min = Math.min(y, h-y);	// y축 최소거리
        
		// x와 y축 최소거리 중 가장 작은 값
		System.out.println(Math.min(x_min, y_min));
		
	}
}
```
{% endraw %}

---

### 코드 설명 

> 💡 굳이 설명이 필요할 까 싶을 정도의 문제이다. 경계선이라 함은 직사각형의 한쪽 면을 얘기하는 것이고, 이는 주어진 점 (x,y)에서 가장 가까운 면까지의 거리를 찾으면 되는 것이다.
> 이를 위해 Math클래스의 min()메소드를 사용하였다.
>

### 마치며

이런 쉬운 문제를 겪으며 느낀 점은, 자바 자체에서 주어진 기본 메소드를 더 많이 활용해야 한다는 점을 깨달았다. 처음 문제를 풀 때 메소드를 사용하지 않고 무식하게 최솟값을 빼가며 비교하고 있던 나를 보았다..;;
