**1. 선택 정렬 ****: 가장 작은 수를 앞으로!**  
 : 선택 정렬은 가장 직관적이고, 먼저 떠올리게 되는 정렬이다.  
 이중 반복문을 통해 첫 번째~주어진 배열의 끝 번째까지 반복하며   
이중 가장 작은 값을 찾아(선택) 정렬 순서에 따라 앞으로 이동 시켜 준다.

---

**2-1. 예제**

> 💡 아래 숫자들을 오름차순으로 정렬하는 프로그램을 작성하세요
>
> 1,10,5,8,7,6,4,3,2,9

  
**2-2. 코드**

{% raw %}
```java
public class Main {

	public static void main(String[] args) {//1. 선택 정렬
		int min = 99;
		int temp,index = 0;
		int[] arr = {
				1,10,5,8,7,6,4,3,2,9
		};
		for(int i=0;i<10;i++)
		{
			min = 999;
//한번 돌 때마다 최솟값은 999(현재 존재하는 모든 값보다 큰 값)을 넣어줘야 한다.
			for(int k=i;k<10;k++)
			{
				if(min>arr[k])
				{
					min = arr[k];
					index = k;
				}		
			}//이중 for문 한번 돌면 i번째로 작은 값이 선택된다.
			temp = arr[i];//아래 과정을 통해 선택된 값이 원래 있던 자리와 i번째 자리를 교체해 준다.
			arr[i] = min;
			arr[index] = temp;
		}
		for(int i=0;i<arr.length;i++)
			System.out.print(arr[i]+" ");
	}

}
```
{% endraw %}

선택 정렬은 우리가 생각하는 가장 기본적인, 그러나 효율적이지는 않은 정렬 방법이다.

---

**3.시간 복잡도**

> 💡 선택 정렬의 시간 복잡도는 O(N^2)이다. 
> 정렬해야 할 데이터의 개수가 100개라면 최소 10000번의 연산을 진행해야 한다는 뜻.
