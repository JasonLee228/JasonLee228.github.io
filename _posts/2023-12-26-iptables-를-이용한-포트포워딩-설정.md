- 포트포워딩 설정

{% raw %}
```java
	iptables -t nat -A PREROUTING -p tcp --dport {출발포트} -j REDIRECT --to-port {도착포트}
```
{% endraw %}

- 예시) 80 포트를 8080 포트로 포워딩
    - sudo iptables -t nat -A PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 8080

- iptables 설정 확인

{% raw %}
```java
sudo iptables -t nat -L --line-numbers
```
{% endraw %}

- 포트포워딩 영구 저장
  이렇게 설정한 포트포워딩은 재부팅 시 리셋된다.

  해당 설정을 재부팅 후에도 계속 유지하고 싶다면 또 다른 패키지가 필요하다.

{% raw %}
```text
sudo apt update && sudo apt upgrade
```
{% endraw %}

apt를 이용해 다운 받을 예정이기 때문에 일단 update와 upgrade를 수행해준다.

{% raw %}
```text
sudo apt install iptables-persistent
```
{% endraw %}

저장 명령

{% raw %}
```java
sudo netfilter-persistent save
```
{% endraw %}
