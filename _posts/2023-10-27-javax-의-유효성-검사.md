`javax.validation` 패키지는 Java에서 데이터 유효성 검사(Validation)를 수행하기 위한 다양한 어노테이션을 제공합니다. 이러한 어노테이션을 사용하면 객체의 필드에 대한 제약 조건을 정의하고 이를 검사할 수 있습니다. 

아래는 몇 가지 주요 `javax.validation` 어노테이션과 그 사용 방법에 대한 간략한 설명입니다:

1. `@NotNull`: 필드가 null이 아닌지 확인합니다.
  {% raw %}
  ```java
  @NotNull
  private String name;

  ```
  {% endraw %}

1. `@Size`: 문자열 또는 배열의 크기를 제한합니다.
  {% raw %}
  ```java
  @Size(min = 2, max = 50)
  private String username;

  ```
  {% endraw %}

1. `@Min` 및 `@Max`: 숫자 필드의 최소 및 최대값을 지정합니다.
  {% raw %}
  ```java
  @Min(18)
  @Max(100)
  private int age;

  ```
  {% endraw %}

1. `@Pattern`: 정규 표현식을 사용하여 문자열 패턴을 확인합니다.
  {% raw %}
  ```java
  @Pattern(regexp = "^[A-Za-z0-9]+$")
  private String password;

  ```
  {% endraw %}

1. `@Email`: 이메일 주소의 유효성을 검사합니다.
  {% raw %}
  ```java
  @Email
  private String email;

  ```
  {% endraw %}

1. `@NotEmpty`: 문자열, 컬렉션 또는 배열이 비어 있지 않은지 확인합니다.
  {% raw %}
  ```java
  @NotEmpty
  private List<String> roles;

  ```
  {% endraw %}

1. `@AssertTrue` 및 `@AssertFalse`: 논리식을 평가하여 `true` 또는 `false` 여부를 확인합니다.
  {% raw %}
  ```java
  @AssertTrue
  private boolean agreedToTerms;

  @AssertFalse
  private boolean isBanned;

  ```
  {% endraw %}

1. `@DecimalMin` 및 `@DecimalMax`: 실수(부동소수점) 필드의 최소 및 최대값을 지정합니다.
  {% raw %}
  ```java
  @DecimalMin("0.0")
  @DecimalMax("100.0")
  private double price;

  ```
  {% endraw %}
