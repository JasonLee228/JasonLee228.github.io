1. 이벤트 관련 용어

> 💡 - 이벤트 소스 : 이벤트를 발생시킨 GUI컴포넌트
> - 이벤트 객체 : 발생한 이벤트에 대한 정보(이벤트 종류, 이벤트 소스, 화면 좌표, 마우스 버튼 종류, 눌러진 키 등)를 답는 객체로서, 이벤트에 따라 서로 다른 정보가 저장된다.
> - 이벤트 리스너 : 이벤트를 처리하는 코드로서 컴포넌트에 등록되어야 작동 가능하다.
> - 이벤트 분배 스레드 : 이벤트 기반 프로그래밍의 핵심 요소로서 무한 루프를 실행하는 스레드이다. 자바 가상 머신으로부터 이벤트의 발생을 통지받아, 이벤트 소스와 이벤트 정류를 결정하고 이에 따라 적절한 이벤트 객체를 생성하고 이벤트 리스너를 찾아 호출한다.

|   |   |   |
| --- | --- | --- |
| 이벤트 객체 | 이벤트 소스 |  이벤트가 발생하는 경우 |
| ActionEvent | JButton, JMenuItem, JTextField | 버튼의 선택 또는 텍스트 입력 후 엔터 키 입력. |
| ItemEvent | JCheckBox, JRatioButton, JCheckBoxMenuItem |  체크박스의 선택, 해제, 라디오버튼의 선택 상태가 변할 때 |
| ListSelectionEvent | JList | 리스트에서 선택된 아이템이 변경될 때 |
| keyEvent | component | 키가 눌려지거나 눌러진 키가 떼어질 때 |
| MouseEvent | component | 마우스 버튼과 움직임, 휠 등 마우스 관련된 모든 활동에 대해 |
| FocusEvent | component | 컴포넌트가 포커스를 받거나 잃을 때 |
| 등등,, |   |   |

1. 이벤트 리스너의 종류

> 💡 JDK는 개발자에게 이벤트 리스너 인터페이스를 제공한다. 이벤트 처리를 위해서는 해당 리스너의 인터페이스를 상속받고, 모든 메소드를 구현해주면 된다.
> 인터페이스의 위치는 java.awt.event안에 있다.

1. 자바의 이벤트 리스너 작성 과정

> 💡 1) 이벤트와 이벤트 리스너 선택 → 목적에 적합한 이벤트와 리스너 인터페이스 선택
> 2) 이벤트 리스너 클래스 작성 → 리스너 인터페이스를 상속받는 클래스를 작성하고 추상 메소드 모두 구현
> 3) 이벤트 리스너 등록 → 이벤트를 받을 스윙 컴포넌트에 이벤트 리스너 등록.

1. 이벤트 리스너 작성 방법 3가지

1) 독립 클래스로 Action 이벤트 리스너 만들기

> 💡 독립된 다른 클래스로 이벤트 리스너 클래스를 작성하는 방법이다.
> 리스너 이벤트 코드가 길 때 적합하고, 가장 전형적으로 사용하는 방법이나, 리스너 클래스에서 다른 클래스 맴버(리스너 사용 클래스)에 접근하기 어려운 단점을 가지고 있다.

{% raw %}
```java
/*
1. 리스너를 받을 컴포넌트 -> btn
2. 리스너 객체를 만든 위 컴포넌트에 붙여준다.
*/

class MyActionListner implements ActionListener//GUI클래스 외부에 작성된 이벤트 리스너
{
	public void actionPerformed(ActionEvent e) {
		// TODO Auto-generated method stub
		JButton b = (JButton)e.getSource();
		if(b.getText().equals("action"))
			b.setText("액션");
		else {
			b.setText("action");
		}
	}
	
}

class indepclassListner extends JFrame
{
	public indepclassListner() {
		// TODO Auto-generated constructor stub
		setTitle("action listner ex");
		setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
		Container c = getContentPane();
		c.setLayout(new FlowLayout());
		JButton btn = new JButton("action");//1.
		btn.addActionListener(new MyActionListner());//2.
		c.add(btn);
		
		setSize(350,150);
		setVisible(true);
	}
}
```

2) 내부 클래스로 Action 이벤트 리스너 만들기

> 💡 이벤트 리스너를 내부 클래스(inner class)로 작성하는 방법이다. 내부 클래스는 자신을 내포한 클래스의 멤버와 같으므로, 클래스나 슈퍼 클래스인 JFrame에 마음대로 접근할 수 있다는 장점이 있다.

{% raw %}
```java
/*
1. 리스너를 받을 컴포넌트 -> btn
2. 리스너 객체를 만든 위 컴포넌트에 붙여준다.
*/

class innerclassListner extends JFrame
{
	public innerclassListner() {
		// TODO Auto-generated constructor stub
		setTitle("action listner ex");
		setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
		Container c = getContentPane();
		c.setLayout(new FlowLayout());
		JButton btn = new JButton("action");
		btn.addActionListener(new MyactionListner());
		c.add(btn);
		
		setSize(350,150);
		setVisible(true);
	}
	
	private class MyactionListner implements ActionListener
	{//innerclassListner의 클래스 멤버로 만들어진 이벤트 리스너. innerclassListner의 타 멤버나
		//JFrame의 멤버에 마음대로 접근 가능.
		@Override
		public void actionPerformed(ActionEvent e) {
			// TODO Auto-generated method stub
			JButton b = (JButton)e.getSource();
			if(b.getText().equals("action"))
				b.setText("액션");
			else {
				b.setText("action");
			}
			//innerclassListner.this.setTitle(b.getText());
			setTitle(b.getText());//두개 같음.
		}
		
	}
}
```
