### Request Mapping

{% raw %}
```javascript
@ReqeustMapping("/hello")
public String hello() {...}
-> HTTP method 상관 없이 호출됨.
```
{% endraw %}

> 💡 `@RequestMapping()` 의 속성에 요청 url은 배열로 제공이 가능하다.
> ex. @RequestMapping({"/hello-basic", "/hello-go"})

- Spring boot 3.0 이후 매핑의 변경점.

> 💡 3.0 이전에서는 요청 url 에 `“hello”` 와 `"hello/"` 가 같았지만, 
> 3.0 이상의 버전에서는 둘이 다른 매핑정보로 쳐진다.

#### MultiValueMap

- MAP과 유사한데, 하나의 키에 여러 값을 받을 수 있다.

- HTTP header, HTTP 쿼리 파라미터와 같이 하나의 키에 여러 값을 받을 때 사용한다. keyA=value1&keyA=value2

- Example

{% raw %}
```java
MultiValueMap<String, String> map = new LinkedMultiValueMap();
map.add("keyA", "value1");
map.add("keyA", "value2");
//[value1,value2]
List<String> values = map.get("keyA");
```
{% endraw %}

### RequestParam, ModelAttribute

- 기존에 HttpServletRequest에서 받아오던 파라미터를 어노테이션을 이용해서 받아올 수 있다.

#### RequestParam 어노테이션 이용하기

1. 기본 이용

{% raw %}
```java
@ResponseBody
@RequestMapping("/request-param-v3")
public String requestParamV2(
            @RequestParam("username") String memberName,
            @RequestParam("age") int memberAge) {
		...
}
```
{% endraw %}

1. 파라미터 명 생략 가능(변수명 이용)

{% raw %}
```java
@ResponseBody
@RequestMapping("/request-param-v3")
public String requestParamV3(
        @RequestParam String username,
        @RequestParam int age) {
		...
}
```
{% endraw %}

1. 어노테이션 생략 가능(추천은,,가독성 위해 넣는게 좋을 듯 하다.)

{% raw %}
```java
@ResponseBody
@RequestMapping("/request-param-v4")
public String requestParamV4(
        String username,
        int age) {
		...
}
```
{% endraw %}

1. 필수 여부 설정 가능

> _주의) int 와 같은 primitive type 은 null을 넣을 수 없기 때문에 비필수라 하더라도 500 error가 발생할 수 있다.   
> 비필수인 경우에는 null 허용 가능한 래퍼 클래스를 사용하자._

{% raw %}
```java
@ResponseBody
@RequestMapping("/request-param-required")
public String requestParamRequired(
        @RequestParam(required = true) String username,
        @RequestParam(required = false) Integer age) {
		...
}
```
{% endraw %}

1. 기본 값 설정 기능

> 문자열의 경우에는 빈 문자열(””) 가 들어오면 기본값으로 설정되니 주의하자.

{% raw %}
```java
@ResponseBody
@RequestMapping("/request-param-default")
public String requestParamDefault(
        @RequestParam(defaultValue = "guest") String username,
        @RequestParam(defaultValue = "-1") int age) {
		...
}
```
{% endraw %}

1. Map을 통해 파라미터 받아올 수 있다.

{% raw %}
```java
@ResponseBody
@RequestMapping("/request-param-map")
public String requestParamMap(
        @RequestParam Map<String, Object> paramMap) {

    log.info("username = {}, age = {}", paramMap.get("username"), paramMap.get("age"));
    return "ok";
}
```
{% endraw %}

#### modelAttribute 이용하기

- 객체가 있을 때 어노테이션을 이용해 자동으로 값을 바인딩시킬 수 있다.

- 스프링에서는 해당 어노테이션이 있을 경우 객체 생성 및 setter 이용하여 값 바인딩을 자동으로 실행한다.

> **프로퍼티**  
> 객체에 getUsername() , setUsername() 메서드가 있으면, 이 객체는 username 이라는 프로퍼티를 가지고 있다.

{% raw %}
```java
@ResponseBody
@RequestMapping("/model-attribute-v1")
public String modelAttributeV1(@ModelAttribute HelloData helloData) {

    /**
     * @ModelAttribute 가 있다면 스프링에서는 객체 생성,
     * setter 이용하여 파라미터 값 바인딩을 자동으로 실행해준다.
     * "프로퍼티"
     */

    log.info("helloData = {}", helloData);
    return "ok";
}
```
{% endraw %}

- 물론 어노테이션은 생략 가능하다.

{% raw %}
```java
@ResponseBody
@RequestMapping("/model-attribute-v2")
public String modelAttributeV2(HelloData helloData) {

    log.info("helloData = {}", helloData);
    return "ok";
}
```
{% endraw %}

> **어노테이션 생략 시 스프링에서 인식하는 방식**  
> String , int , Integer 같은 단순 타입 = @RequestParam  
> 나머지 = @ModelAttribute (argument resolver 로 지정해둔 타입 외)
