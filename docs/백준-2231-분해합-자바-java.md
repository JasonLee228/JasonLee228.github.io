[2231번: 분해합](https://www.acmicpc.net/problem/2231)

### 문제

> 💡 어떤 자연수 N이 있을 때, 그 자연수 N의 분해합은 N과 N을 이루는 각 자리수의 합을 의미한다. 어떤 자연수 M의 분해합이 N인 경우, M을 N의 생성자라 한다. 예를 들어, 245의 분해합은 256(=245+2+4+5)이 된다. 따라서 245는 256의 생성자가 된다. 물론, 어떤 자연수의 경우에는 생성자가 없을 수도 있다. 반대로, 생성자가 여러 개인 자연수도 있을 수 있다.
>
> 자연수 N이 주어졌을 때, N의 가장 작은 생성자를 구해내는 프로그램을 작성하시오.

---

### 입력

> 💡 첫째 줄에 자연수 N(1 ≤ N ≤ 1,000,000)이 주어진다.

---

### 출력

> 💡 첫째 줄에 답을 출력한다. 생성자가 없는 경우에는 0을 출력한다.

---

### 예제 입력 1

{% raw %}
```text
216
```
{% endraw %}

### 예제 출력 1

{% raw %}
```text
198
```
{% endraw %}

---

### 원리

> 💡 브루트 포스 알고리즘은 나타날 수 있는 모든 경우를 다 탐색하는 알고리즘이다.
> 1부터 주어진 수까지 반복문을 돌리면서, 각 자릿수와 증가수 i를 합해주어 값이 같다면 생성자를 갱신해주는 원리이다.

### 풀이 코드(최종)

{% raw %}
```java
import java.util.*;
import java.io.*;
class Main {
	static public void main(String []args) {

        Scanner s = new Scanner(System.in);
        int N = s.nextInt();
        int M=1000000;
        for(int i=1;i<N;i++)
        {
            int result=0;
            
            String num = Integer.toString(i);
            String[] str = num.split("");
            
            result+=i;
            for(int k=0;k<str.length;k++)
            {
                result += Integer.parseInt(str[k]);
            }

            if(result == N && M>i )
            {
                M = i;
            }

        }
        if(M == 1000000)
        {
            M=0    ;
        }
        System.out.println(M);

    }
}
```
{% endraw %}

---

### 코드 설명 

> 💡 입력으로 주어질 수 있는 최대 수인 1,000,000을 초기 생성자로 잡고, 
> 1부터 N까지 반복문을 돌리며, 각 자릿수와 i를 합해준다. 
> 이 때, 합해준 값인 result가 N과 같다면, 생성자이기 때문에 생성자를 갱신해주게 된다.
> 갱신 전에, 이전의 생성자보다 작은 지를 판단해주는 조건문이 있고, 작지 않다면 갱신하지 않는다.

---

### 마치며

> 💡 처음에 생성자가 없을 수가 있나?라는 단순한 생각이 있었는데, 이를 알아보기 위해 1부터 500까지 모든 수의 생성자를 구해보는 노가다를 해 보았었다. 이런 노가다 덕분에 생성자가 없거나 여러 개일 수 있다는 것을 알 수 있었고, 문제를 풀어내는 데에 도움이 되었다.
