[2447번 - 별 찍기 - 10](https://www.acmicpc.net/problem/2447)

### 문제

> 💡 재귀적인 패턴으로 별을 찍어 보자. N이 3의 거듭제곱(3, 9, 27, ...)이라고 할 때, 크기 N의 패턴은 N×N 정사각형 모양이다.
>
> 크기 3의 패턴은 가운데에 공백이 있고, 가운데를 제외한 모든 칸에 별이 하나씩 있는 패턴이다.
>
> * * *
> *   *
> * * *
> N이 3보다 클 경우, 크기 N의 패턴은 공백으로 채워진 가운데의 (N/3)×(N/3) 정사각형을 크기 N/3의 패턴으로 둘러싼 형태이다. 예를 들어 크기 27의 패턴은 예제 출력 1과 같다.

---

### 입력

> 💡 첫째 줄에 N이 주어진다. N은 3의 거듭제곱이다. 즉 어떤 정수 k에 대해 N= (3의 k제곱)이며, 이때 1 ≤ k < 8이다.

---

### 출력

> 💡 첫째 줄부터 N번째 줄까지 별을 출력한다.

### 문제 알고리즘 풀이

문제의 패턴을 보면, 9개로 구역을 나눠서 생각해 볼 수 있다.  
최초 3*3을 예시로 들어 보면, 

![image](/assets/images/2b7d0a97c93a4956bfbe2643cb9eeaca.png)

 '가운데' , 즉 4번째 이후 5번째 칸은 비워 놓는다는 것을 알 수 있다.   
이를 좌표로 나타내면 (1,1)이라고 표현할 수 있다.

다음으로 9*9의 형태를 보게 되면, 위의 3*3형태의 배열을 한 개의 원소라고 보았을 때  
3*3의 형태일 때와 같이 5번째 칸이 비워져 있다고 볼 수 있고, 이는 아래 그림인 27*27의 형태일 때도 동일하다.

![image](/assets/images/2366386008de43b283d7732b4f660f98.png)

![image](/assets/images/aeb013a0577a49189689a579017b405d.png)

이제 거꾸로 생각해 보자.   
숫자 N 이 주어졌을 때, 반복되는 형태를 가진, 하나의 원소로 보고 있는 형태는 N/3인 것을 알 수 있고, 그렇게 나누어진 총 9개의 원소 중 5번째 원소는 비워둔다. 이게 최종적으로 볼 수 있는 형태이다.

1) N=27일 때, 우리는 전체를 원소를 한 변의 길이 9인 9개의 블록으로 나눌 수 있다. 이중 5번째 블록, 위 그림에서 빈칸은 비워주는 것으로 한다. 이후, 비워주기로 하지 않은 나머지 8개의 블록은 다시 각각 따로 불러준다.

![image](/assets/images/f5e79bca98ef4733898bdd7e8259f1f6.png)

2) N=9일 때, 전체를 한 변의 길이 3인 9개의 블록으로 나눌 수 있고, 마찬가지로 5번째 블록은 비워준다. 이후 나머지 블록을 불러내 준다.

![image](/assets/images/b9d9fc1feb6b47d59fb24c9f98027675.png)

3) N=3일 때, 전체를 한 변의 길이 1인 9개의 블록으로 나눌 수 있고, 5번째 블록은 비워준 뒤 나머지 블록은 다시 불러준다.

![image](/assets/images/ff2dceba1be44270a08eabfb253b4ca8.png)

4) N=1이 되는데, 이런 상황에는 결국 나눌 블록이 없고, 이럴 때 비로소 '*'로 채워주면 되는 것이다.

결국 비워진 칸들을 제외한 나머지 칸은 N=1이 될 때까지 재귀호출 되고, *로 채워지게 되는 것.

### 풀이 코드(최종)

{% raw %}
```java
import java.util.Scanner;

public class Main {
	static char[][] arr;
	public static void star(int n, int x, int y, Boolean no) {
		
		if(n==1&&!no)
		{
			arr[x][y]='*';
			return;
		}
		else if(no)
		{
			for(int i=x;i<x+n;i++)
				for(int k=y;k<y+n;k++)
					arr[i][k]=' ';
			return;
		}

		int count=0;
		int size = n/3;
		for(int i=x;i<x+n;i+=size)
		{
			for(int k=y;k<y+n;k+=size)
			{
				count++;
				if(count==5)
				{					
					star(size, i, k, true);
				}
				else {
					star(size, i, k, false);
				}

			}
		}
	}
	
	public static void main(String[] args) {
    
		Scanner s = new Scanner(System.in);
		int n = s.nextInt();
		arr = new char[n][n];
		
		star(n,0,0,false);
		
		for(int i=0;i<n;i++)
		{
			for(int k=0;k<n;k++)
				System.out.print(arr[k][i]);
			System.out.println();
		}

		s.close();
	}
}
```

### 코드 설명 

> 💡 최초로 받은 N에 대해서 N*N크기의 배열을 생성한 뒤, 알고리즘 설명처럼 큰 부분부터 점점 작게 나아가는 형태를 띄고 있다. 
>
> star() 메소드의 구성을 보면,
> 1. 한 변의 크기를 size = N/3으로 설정, 이중 for문을 통해 한 변씩 나아간다. 
> 2. 나아갈 때 마다 count는 1씩 늘어나고, count=5라는 것은 5번째 블록을 의미하기 때문에 빈칸으로 채워준다. 
> 3. 빈칸을 의미하는 것은 Boolean 변수인 no를 통해 판별한다. no == true일 때 공백으로 배열을 채워줄 수 있도록 했다. 이후 return.
> 4. 빈칸이 되지 않은 채로 N==1이 된 블록에 한해서, no==false라는 조건에 부합할 때 별로 채워주게 된다.
>
> 5. print 로 배열을 반복출력하게 되면 출력 횟수가 너무 많아져 시간초과가 나게 된다.
> 이를 위해서 StringBuilder를 사용하여 한번에 출력해줘 시간을 줄인다.
