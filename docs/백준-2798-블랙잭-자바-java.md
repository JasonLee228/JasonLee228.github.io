[2798번: 블랙잭](https://www.acmicpc.net/problem/2798)

### 문제

> 💡 카지노에서 제일 인기 있는 게임 블랙잭의 규칙은 상당히 쉽다. 카드의 합이 21을 넘지 않는 한도 내에서, 카드의 합을 최대한 크게 만드는 게임이다. 블랙잭은 카지노마다 다양한 규정이 있다.
>
> 한국 최고의 블랙잭 고수 김정인은 새로운 블랙잭 규칙을 만들어 상근, 창영이와 게임하려고 한다.
>
> 김정인 버전의 블랙잭에서 각 카드에는 양의 정수가 쓰여 있다. 그 다음, 딜러는 N장의 카드를 모두 숫자가 보이도록 바닥에 놓는다. 그런 후에 딜러는 숫자 M을 크게 외친다.
>
> 이제 플레이어는 제한된 시간 안에 N장의 카드 중에서 3장의 카드를 골라야 한다. 블랙잭 변형 게임이기 때문에, 플레이어가 고른 카드의 합은 M을 넘지 않으면서 M과 최대한 가깝게 만들어야 한다.
>
> N장의 카드에 써져 있는 숫자가 주어졌을 때, M을 넘지 않으면서 M에 최대한 가까운 카드 3장의 합을 구해 출력하시오.

---

### 입력

> 💡 첫째 줄에 카드의 개수 N(3 ≤ N ≤ 100)과 M(10 ≤ M ≤ 300,000)이 주어진다. 둘째 줄에는 카드에 쓰여 있는 수가 주어지며, 이 값은 100,000을 넘지 않는 양의 정수이다.
>
> 합이 M을 넘지 않는 카드 3장을 찾을 수 있는 경우만 입력으로 주어진다.

---

### 출력

> 💡 첫째 줄에 M을 넘지 않으면서 M에 최대한 가까운 카드 3장의 합을 출력한다.

### 원리

> 💡 브루트 포스 알고리즘은 나타날 수 있는 모든 경우를 다 탐색하는 알고리즘이다.
> 이 문제의 경우도 세 가지 카드를 합하는 경우를 모두 탐색한 뒤, 
> 문제에서 요구하는 최댓값 M을 넘지 않으면서 최대인 합의 경우를 나타내면 된다.
> 3중 반복문을 통해 해결할 수 있다.

### 풀이 코드(최종)

{% raw %}
```java
import java.util.*;

class Main {
    public static StringBuilder sb = new StringBuilder();
   
	static public void main(String []args) {
		Scanner s = new Scanner(System.in);
        int n = s.nextInt();
        int m = s.nextInt();
        
        int[] arr = new int[n];
        
        for(int i=0;i<n;i++)
        	arr[i] = s.nextInt();
        
       int max = search(arr,n,m);
        
       System.out.println(max);
	
    }


    public static int search(int[] arr,int n,int m)
    {
        int result=0;
        int max=0;
        
        	
				for(int index=0;index<n-2;index++)//첫 번째 수
				{
					for(int i=index+1;i<n-1;i++)//두 번째 수
					{
				
							for(int k=i+1;k<n;k++)//세 번째 수
							{
	              max = arr[index]+arr[i]+arr[k];
								if(max==m)
								{
					        		return max;
								}
                                else if(result<max&&max<m)
                                {
                                    result = max;
                                }
							}
						}
				}
    return result;
    }
}
```

### 코드 설명 

> 💡 위의 경우에서는 정말 모든 경우를 다 찾아보는 방법을 사용했다.
> 하지만, 만약 문제와 달리 카드의 개수가 굉장히 많을 경우에는 시간적 손실이 굉장히 클 것이다. 
> 이를 방지할 수 없을까? 생각에 조건문 두 개를 추가했다.
>

{% raw %}
```java
import java.util.*;

class Main {
    public static StringBuilder sb = new StringBuilder();
   
	static public void main(String []args) {
		Scanner s = new Scanner(System.in);
        int n = s.nextInt();
        int m = s.nextInt();
        
        int[] arr = new int[n];
        
        for(int i=0;i<n;i++)
        	arr[i] = s.nextInt();
        
       int max = search(arr,n,m);
        
       System.out.println(max);
	
    }


    public static int search(int[] arr,int n,int m)
    {
        int result=0;
        int max=0;
        
        	
				for(int index=0;index<n-2;index++)//첫 번째 수
				{
                    if(arr[index]>=m)// 1.
                        continue;
					for(int i=index+1;i<n-1;i++)//두 번째 수
					{
                        if(arr[index]+arr[i]>=m)//2. 
                            continue;
						for(int k=i+1;k<n;k++)//세 번째 수
						{
                            max = arr[index]+arr[i]+arr[k];
						    if(max==m)
							{
					        		return max;
								}
                                else if(result<max&&max<m)
                                {
                                    result = max;
                                }
							}
						}
				}
    return result;
    }
}
```
{% endraw %}

> 💡 1. 의 조건문은, 최댓값 M보다 카드에 적힌 수가 더 크거나, 같을 경우이다.
> 위의 경우에는 다른 카드의 수를 합치기도 전에 이미 M을 초과하니, 다음 경우를 확인 할 필요가 없기 때문에 continue;를 통해 다음 경우로 바로 넘어가 준다.
>
> 2. 의 조건문은, 첫, 두번째 수를 합했을 때 이미 M보다 크게 됐을 경우이다. 이 경우에도 1. 의 경우와 같이 다음 수를 확인할 필요가 없어지니 continue.
